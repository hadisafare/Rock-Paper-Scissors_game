# Rock Paper Scissors 🎮

A simple Rock Paper Scissors console game built with Kotlin.

## About

This is one of my first Kotlin projects, created to practice basic programming concepts and problem-solving.

The player plays against the computer, and the first one to reach 3 points wins the game.

## Features

- Rock, Paper, Scissors gameplay
- Random computer choices
- Score tracking
- First to 3 points wins
- Exit option
- Case-insensitive user input

## Concepts Practiced

- Variables
- `while` loops
- `if` statements
- Lists
- `random()`
- User input with `readln()`
- String functions
- `break`
- Increment operators

## How to Run

Run the `main()` function in a Kotlin environment.
